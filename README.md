# ArabicSRT_Converter
A simple Python script to convert text files from Windows-1256 encoding to UTF-8 encoding.


## Features

- Converts text files from Windows-1256 to UTF-8 encoding
- Supports converting all `.srt` files in a directory or a single specified file
- Command-line interface with options for batch or single file conversion
- Handles encoding errors gracefully

## Usage

### Convert a specific file by passing the filename as an argument:
```bash
python converter.py "filename.srt"
```
### Run without arguments to get interactive options:
Choose an option:
a - Convert all .srt files in the current directory
s - Convert a single .srt file
